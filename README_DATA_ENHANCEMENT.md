## 💡 Key Concepts

**Outlier Detection:**
- Z-score: >3 std devs from mean
- IQR: Outside Q1-1.5×IQR to Q3+1.5×IQR
- Price jumps: >20% change in 1 hour

**Data Cleaning:**
- Method: Linear interpolation
- Preserves: Timestamp continuity
- Updates: Database directly

**Historical Fetching:**
- Source: Bybit API
- Batch size: 200 candles
- Conflict: Skip duplicates
