<objective>
Build the **forward-paper-test apparatus** for the three Tier-1 opt-in features (vol parity, maker, funding) so the operator can run each in isolation against the baseline, publish PSR-with-bootstrap-CI evidence, and have a code-level gate that blocks default-on flips of these flags until evidence is published.

Purpose: SC-1 from ROADMAP Phase 5 — "per-feature default-on flips are blocked until PSR with bootstrap CI is published." MLCL-01.

Output: Host-runnable Python package under `scripts/forward_paper_test/` (CLI launcher + PSR-CI computation + profile definitions), a config-time pytest gate in trading-engine that fails on premature `default=True`, evidence directory scaffold under `.planning/evidence/forward_paper_test/`, and an operator runbook documenting the 7-day evidence loop.

**Important scope clarification:** This plan delivers the **apparatus and gate**, NOT the 7-day evidence itself (3 flags × ≥7 wall-clock days each = ≥21 days, operator action). The deliverable is "operator can produce evidence, and code refuses to ship a default-on flip without it." Running the evidence loop is operator homework, encoded in the runbook.
</objective>

From `services/risk-metrics-service/app/sharpe_metrics.py`:
- `probabilistic_sharpe_ratio(returns: np.ndarray, benchmark_sr: float = 0.0) -> float`
  Returns PSR in [0, 1]; NaN on zero-variance input (Plan 04-10 zero-safe pattern applies for baselines).

From `services/tournament-harness/app/significance/bootstrap.py`:
- `derive_seed(tournament_id: str, symbol: str) -> int`
  Blake2b-derived 31-bit seed for reproducibility (CD-07 pattern).
- `stationary_block_bootstrap_pvalue(paired_diffs: np.ndarray, *, metric_fn, n_resamples: int = 10_000, seed: int, alternative: str = "greater") -> Dict[str, float]`
  Returns `{observed_metric, p_value, n_oos_bars, block_size, n_resamples}` — Politis-Romano stationary block bootstrap with additive smoothing.

From `services/trading-engine/app/config.py` (lines 124, 153, 177):
- `enable_vol_targeting: bool = Field(default=False, ...)`
- `enable_funding_gate: bool = Field(default=False, ...)`
- `prefer_maker_orders: bool = Field(default=False, ...)`
Each has a code-comment block referencing "forward-paper-test ≥7 days" — this plan operationalises that promise.

Cross-service import pattern (mirrors how `services/tournament-harness/app/runner/metrics_bridge.py` reaches into `services/ml-retraining-service/app/`):
- The forward-paper-test scripts are HOST-runnable (operator runs them outside Docker against paper-trade logs). They prepend `services/risk-metrics-service/app/` and `services/tournament-harness/app/significance/` to `sys.path` to import the canonical kernels. NEVER copy-paste the kernel bodies.

PSR CI semantics (distinct from Phase 4's p-value):
- Phase 4 produces a **one-tailed p-value** under H0: lift = 0. That's a hypothesis test.
- This plan produces a **percentile confidence interval on the PSR statistic itself**. For each bootstrap resample, compute `probabilistic_sharpe_ratio(resampled_returns)`, then take the 2.5th/97.5th percentiles. Output `{psr_point: float, psr_ci_low: float, psr_ci_high: float, n_resamples: int, block_size: int, seed: int}`.
