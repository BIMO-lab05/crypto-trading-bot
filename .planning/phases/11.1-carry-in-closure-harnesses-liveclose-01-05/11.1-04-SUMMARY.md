## Decisions Made

- **Filename underscores, not hyphens.** The plan's `files_modified` paths used hyphens (`liveclose-03-psr-evidence.py`); the test imports and 5+ acceptance criteria used underscores. Python modules cannot contain hyphens — underscores win. Documented under Deviations (Rule 3).
- **Consecutive-day detection on max-streak, not min-max span.** The plan said "≥7 consecutive trading-day rows"; a span-based check (`max - min >= 6 days`) would incorrectly pass on gap fixtures. The harness counts the longest run where `dates[i+1] - dates[i] == timedelta(days=1)`.
- **Status embedded in payload then popped.** `build_evidence_payload` returns a dict that includes the verdict status; `main()` pops it before forwarding as `extra=` to `write_evidence` (whose collision guard would otherwise raise `ValueError`). This makes the verdict introspectable from a single helper return without breaking the existing `_common` contract.
- **`sqlite3.Row` cast to `dict` at query time.** JSON serialization downstream cannot handle `sqlite3.Row` objects; the harness casts every row via `dict(zip(col_names, row))` before grouping.
