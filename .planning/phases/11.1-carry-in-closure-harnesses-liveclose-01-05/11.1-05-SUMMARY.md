## Decisions Made

- **Underscored module name (Rule 3 deviation; see below).** Filed in deviations.
- **Mirror, don't import, VALID_VERDICTS.** Importing a test module into a production script is an anti-pattern (Python's test collection would re-run the test, and module-load side effects could leak). Both copies (canonical + mirror) are flagged load-bearing in the harness docstring and in `test_valid_verdicts_matches_canonical_source` so any future drift surfaces in CI.
- **Technical PASS = AWAITING_HUMAN, not COMPLETE.** This matches Plan 02/03/04 framework. The operator still has to commit the verdict.json under `.planning/evidence/LIVECLOSE-04/` and flip the LIVECLOSE-04 row in `.planning/state/carry_ins.json`. COMPLETE is reserved for terminal closures with zero operator follow-up.
- **EDGE_FOUND verdict + zero non-null p-values downgrades to INSUFFICIENT_DATA.** Verdict alone is insufficient; bootstrap evidence is required. The verdict field is preserved verbatim in the evidence (we never rewrite the operator's terminal line) but the harness's `status` field downgrades to INSUFFICIENT_DATA.
- **Paper-only refusal happens BEFORE argparse.** TRADING_MODE=LIVE check fires first so an operator who accidentally set the env on a cloud host gets a fast deterministic exit with no IO.
- **"At least one symbol has a non-null bootstrap p-value" interpreted as BOTH axes (`sharpe_pvalue` AND `dir_acc_pvalue`) being non-null for that symbol.** The plan body's `<action>` step 3 explicitly says "count of symbols where both sharpe_pvalue and dir_acc_pvalue are non-None" — the stricter reading. This is also consistent with the upstream win-gate (`services/tournament-harness/app/significance/win_gate.py`), which requires BOTH axes to clear p<0.05 with positive lift for a winning symbol. The `must_haves.truths` line's looser phrasing ("at least one symbol has a non-null bootstrap p-value") is disarmed by the action-step pinning. Encoded in `build_evidence_payload`'s `n_symbols_with_pvalues = sum(1 for pv ... if pv['sharpe_pvalue'] is not None and pv['dir_acc_pvalue'] is not None)`.
