Defect site: `app/handlers/signals.py:212`, the last line of the success path of
`_fetch_market_regime` (`:176-223`) — it returns a dict of regime, adx and a
literal 0.7 confidence.

The value is available on the payload already in hand. `_fetch_market_regime`
calls `/api/v1/indicators/adx/{symbol}` at `:182` and reads
`payload = response.json().get("data", {}) or {}` at `:188`. The same endpoint's
`data.confidence` is what `signal_aggregator.fetch_adx` reads at `:481`
(a guarded float of `data.get("confidence", 0.0)`). Source of the number:
technical-analysis `app/indicators/adx.py::ADXCalculator._calculate_confidence`.

Degraded path to KEEP unchanged (`:214-223`): the `except` branch returns
regime UNKNOWN, adx None, confidence 0.5 and a reason string.

The ONLY arithmetic consumer, `_calculate_enhanced_signal` at `:278`:
`risk_confidence = market_regime.get("confidence", 0.5)`, then the risk leg
appends `risk_confidence * 0.15` to the weights.

**This decides the absent-key rule.** The dict is also serialized into the
response at `:130-138` under `metadata.market_regime`. If a missing confidence
were returned as `None`, the consumer's `.get("confidence", 0.5)` would return
`None` (the key is present) and multiplying it raises — the enhanced path would
degrade through its own exception handler on every TA reply lacking the key.
Therefore, on the success path: resolve the payload's confidence, coerce with a
guarded `float()`, and if it is absent or not coercible, **OMIT the key entirely
from the returned dict** so the consumer's declared 0.5 neutral applies. This
diverges deliberately from the sibling `adx` handling (which returns a present
`None`) because `adx` is surfaced for display and never multiplied. State that
divergence in a comment at the site.

Confirmed: no consumer outside this module reads `metadata.market_regime.confidence`
(the api-gateway and the frontend have zero references), so omitting the key
does not break a rendered field. Re-grep before relying on it.

**TRAP — an existing test pins the 0.7.** `tests/aggregation/test_mirror_literals.py:455`,
inside `test_handler_returns_the_regime_ta_computed`, asserts the returned
confidence equals 0.7. Its parametrized payloads (`:428-447`) carry NO
`confidence` key, so after the fix they exercise the absent-key branch. The
driver helper is `_drive_market_regime(monkeypatch, payload=..., raises=...)` at
`:412-425`. A stub that DOES carry a confidence already exists in this file:
`_adx_response` (`:138-155`, confidence 0.6). The degraded-path tests at
`:458-488` pin the exception branch and must stay green untouched.

Measurement-script analog: `services/trading-engine/scripts/ablation_ensemble_admission.py`
(676 lines) — note the path is under the SERVICE, not repo root, which
22.1-CONTEXT gets wrong. Copy its conventions: module docstring with WHAT THIS
MEASURES / WHAT THIS IS NOT / DETERMINISM / USAGE sections, a constructed
deterministic corpus via builder functions, `argparse` main with `--json`
artifact output and per-arm printed summary lines, non-zero exit on integrity
failure, and a `sys.path` bootstrap so it runs from `services/trading-engine`.
