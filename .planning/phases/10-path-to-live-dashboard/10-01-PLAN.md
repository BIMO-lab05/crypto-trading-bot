D-10-04 — Response shape for GET /api/preflight/carry-ins:
- schema_version (int, =1)
- evaluated_at (ISO 8601 string)
- overall ("DO_NOT_FLIP"|"ALMOST"|"READY") — server-computed
- carry_ins (array — verbatim copy of file's carry_ins[])
- window: {first_all_pass_at: ISO|null, elapsed_seconds: int, required_seconds: int, remaining_seconds: int}
- preflight_summary: {pass: int, fail: int, unknown: int}
- live_readiness (object — joined from /api/preflight/live-readiness per D-10-16; contains schema_version, overall, evaluated_at, checks[]).

D-10-07 — Reset rule: compute all_pass = all(check.status=="PASS" for check in report.checks). If all_pass and _state.first_all_pass_at is None: set it to now_iso(). If not all_pass: set _state.first_all_pass_at = None. Always update last_evaluated_at = now_iso() and last_overall = computed overall.

D-10-08 — UNKNOWN counts as not-PASS for window-reset purposes.

D-10-09 — Required window = env PREFLIGHT_CONTINUOUS_PASS_REQUIRED_SECONDS (default 86400). Read on each request, not cached.

D-10-11 — On trading-engine unreachable OR proxy failure, return 200 with `overall="DO_NOT_FLIP"`. Per-check `live_readiness.checks` may still surface UNKNOWN. Never raise.

D-10-05 — Container path: env PREFLIGHT_CARRY_INS_PATH defaults to /app/planning_state/carry_ins.json. Bind-mount the parent dir ./.planning/state (not the file) — WSL gotcha.

Atomic file write — canonical Python idiom (NO in-repo analog; PATTERNS.md falsifies the CONTEXT.md claim about lifespan/ml.py:195):
- Use tempfile.mkstemp(prefix=f".{path.name}.", suffix=".tmp", dir=str(path.parent)).
- os.fdopen the returned fd as "w", write JSON, f.flush(), os.fsync(f.fileno()).
- os.replace(tmp_name, path) — atomic on POSIX and Windows from Python 3.3+.
