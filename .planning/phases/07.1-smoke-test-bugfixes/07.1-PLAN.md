<objective>
Close the three real bugs that surfaced when Phase 7's audit-driven Playwright smoke was first run against a live stack on 2026-05-14:

1. Strict-mode locator violation on multi-child stale tiles (e.g. PriceTickerGrid has 6 ticker-symbol children, each renders a `<StaleBadge/>` — the bare locator finds 6 elements and strict-mode rejects).
2. Page-level LABELED_STALE rows (Phase3Dashboard, page-level Portfolio) never match — the assertion looks for `[data-testid="{root}"] [data-testid="tile-stale-badge"]` as a direct descendant, but staleness lives deep inside individual tile components nested under the page root.
3. `GATEWAY_ORIGIN = "http://localhost:8000"` hardcode points at api-gateway, which only serves JSON. Smoke's `page.goto(f"{GATEWAY_ORIGIN}/")` returns API root JSON, not the React app, so the smoke can never see any testid even when the frontend renders correctly.

These bugs do NOT invalidate Phase 7 code (gateway endpoints + frontend page + testids + smoke wiring all verified live on 2026-05-14 — `/tmp/tournament-render.png` proves /tournament renders with all expected testids); they are smoke-test design + ingress-architecture gaps.

After this plan: the exact command `pytest tests/integration/test_dashboard_smoke.py --browser=chromium` runs green against the live recreated stack with no patches.
</objective>

And the smoke's LABELED_STALE branch becomes:

  ```python
  scope = row.get("data_testid_scope", "root")
  if scope == "descendant":
      locator = page.locator(f'[data-testid="{testid}"]').locator('[data-testid="tile-stale-badge"]').first
  else:
      locator = page.locator(f'[data-testid="{testid}"] [data-testid="tile-stale-badge"]').first
  expect(locator).to_be_visible()
  ```

And api-gateway's main.py gains a catch-all after every `/api/*` route is registered:

  ```python
  @app.api_route("/{full_path:path}", methods=["GET"], include_in_schema=False)
  async def reverse_proxy_to_frontend(full_path: str, request: Request):
      if full_path.startswith("api/"):
          raise HTTPException(404)
      upstream = os.environ.get("FRONTEND_UPSTREAM", "http://frontend:80")
      async with httpx.AsyncClient() as client:
          target = f"{upstream}/{full_path}"
          resp = await client.get(target, params=request.query_params,
                                  headers={k: v for k, v in request.headers.items() if k.lower() not in HOP_BY_HOP})
          return Response(content=resp.content, status_code=resp.status_code,
                          headers={k: v for k, v in resp.headers.items() if k.lower() not in HOP_BY_HOP})
  ```
