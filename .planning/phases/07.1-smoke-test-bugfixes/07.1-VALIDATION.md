## 4. Gaps Found

**Nyquist gaps:** none.

**Tech-debt items surfaced (NOT Nyquist gaps):**

1. **Local-only `/tmp/phase71-smoke/` conftest workaround.** Operator re-running the smoke against an already-up local stack (mainnet+paper, not recorded-tape) needed an ephemeral conftest in `/tmp/` to no-op the `bootstrap_stack` and `tape_reset` fixtures. The workaround is documented in `07.1-01-SUMMARY.md` (Issues Encountered → Task 4) and `07.1-VERIFICATION.md` (Outstanding Risks #2). It is **not** committed and **not** required for CI (CI's `bootstrap.sh` path is canonical). Promotion to a first-class `--use-running-stack` / `--skip-bootstrap` pytest CLI flag in `tests/integration/conftest.py` is **flagged as tech debt in v1.0 audit, not a Nyquist gap** — the live smoke run covers the regression surface; the missing flag only affects operator convenience for local manual re-runs.

2. **Phase3Dashboard audit row dropped (filed as Phase 7.2).** Phase3Dashboard renders a skeleton-loader `<div class="animate-pulse">` indefinitely when ML predictions are flag-off; no verdict in the current audit schema (`FIXED` / `LABELED_STALE` / `REMOVED`) cleanly fits. Row removed from active audit (16 → 15 rows) and Phase 7.2 filed to fix the underlying frontend defect, then re-add the row. Not a Nyquist gap for Phase 7.1 — the gate that previously required the row is satisfied by PASS-WITH-AMENDMENT (1 descendant row instead of 2), and the underlying defect is Phase 3 page-render, not Phase 7 wiring.

3. **Pre-existing semgrep WARNINGs deferred.** 12 unrelated `docker-compose.unified.yml` container-hardening findings (postgres/timescaledb/redis/rabbitmq/prometheus/grafana + docker.sock surface) logged to `.planning/phases/07.1-smoke-test-bugfixes/deferred-items.md` per GSD SCOPE BOUNDARY rule. None touch the api-gateway block. Out of scope for a smoke-test bugfix phase; requires its own security-hardening plan.

4. **No connection-pool reuse in catch-all.** Each catch-all request opens a new `httpx.AsyncClient` (documented as a `failure_mode` in PLAN). Acceptable for the local smoke consumer; would need a module-level reusable client for production load. Tracked inline in plan, not a Nyquist gap.
