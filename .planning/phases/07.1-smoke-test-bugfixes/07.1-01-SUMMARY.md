## Decisions Made

1. **`/` → `/gateway-info` (not content-negotiation).** Plan's acceptance gate requires `curl /` to return `text/html`. The cleanest, smallest-diff way to honor that without breaking the 4 existing tests that assert the JSON shape is to relocate the JSON to a new path. Content-negotiation cleverness was rejected after advisor consult.
2. **No api-gateway → frontend `depends_on`.** docker-compose.unified.yml already declares `frontend: depends_on: api-gateway: service_healthy`. Adding the reverse edge would create a circular dependency that compose refuses to resolve. The catch-all tolerates a brief 502 window while frontend boots (documented inline in compose comment). This is a deviation from the plan's literal Task 3 step 4 wording — justified under deviation Rule 3 (blocking issue).
3. **Module-level constants for hop-by-hop set.** RFC 7230 §6.1 is stable; encoding the 8 hop-by-hop headers as a `frozenset` is correct and zero-overhead per request.
4. **No new respx dependency.** The plan mentioned `respx` for the unit test, but api-gateway already vendors `pytest-httpx`; `unittest.mock.patch` on `httpx.AsyncClient` is sufficient and avoids an extra dep. All 8 tests pass in-container.

**3. [Rule 2 - Missing Critical] Defense-in-depth bypass list on catch-all**

- **Fix:** Module-level `_GATEWAY_OWNED_PREFIXES = ("api/",)` + `_GATEWAY_OWNED_EXACT` (health, ready, metrics, docs, redoc, openapi.json, ws, gateway-info). Catch-all raises 404 if the requested path is in either set — fails closed.
- **Files modified:** `services/api-gateway/app/main.py`

### Task 4 (end-to-end smoke verification) — partial

**Status:** Tasks 1+2+3 mechanically verified (grep gates, py_compile, JSON schema, 3 live curl gates passing); the audit-driven Playwright smoke against the running local stack was NOT executed end-to-end. Deferred to orchestrator post-merge / CI re-verification.

**Why deferred:**

1. **Running stack is mainnet+paper, NOT recorded-tape.** The Phase 2 smoke fixtures (`bootstrap_stack`, `tape_reset`) assume `MARKET_DATA_SOURCE=tape` on `bybit-connector` so `/admin/tape/reset` returns 200. The host stack the operator has running was booted in mainnet-prices+paper-trading mode (per ADR-010 / CLAUDE.md `BYBIT_TESTNET=false`); `POST http://localhost:8001/admin/tape/reset` returns 404. The smoke's `tape_reset` fixture would fail at setup time.
2. **bootstrap_stack fixture clones a fresh isolated stack.** The fixture shells to `bootstrap.sh` from `/tmp/cb-test-<sha>`. That sub-clone is missing the worktree's `.env` files (gitignored), so `docker compose up` errors with `env file /tmp/.../services/notification-service/.env not found`. Bootstrap is designed for CI (where the fresh clone has all env files); locally it would need pre-staging.
3. **Pytest fixture-override semantics.** I tried the orchestrator's suggested `/tmp/` ephemeral plugin (`PYTHONPATH=/tmp/smoke-override pytest -p sitecustomize_plugin`). `--fixtures` showed the override fixtures registered, but `tests/integration/conftest.py`'s `bootstrap_stack` still won during actual fixture resolution because closer-scope conftests outrank plugin-defined fixtures of the same name in pytest's lookup order. Net effect: smoke setup still tried to run `./bootstrap.sh` and failed on the missing env file.
