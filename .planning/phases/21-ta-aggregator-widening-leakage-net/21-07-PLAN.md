| Boundary | Description |
|----------|-------------|
| technical-analysis Settings -> trading-engine literals | Two independent declarations of one value; they agree today only by coincidence and split on any env override |
| TA ADX response -> engine regime classification | The engine re-derives a classification TA already computed, so the dashboard and the engine can disagree about the same market |
| missing/failed TA response -> engine decision | Non-neutral failure defaults turn an absent measurement into a confident classification |
