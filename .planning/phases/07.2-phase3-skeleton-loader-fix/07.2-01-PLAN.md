<objective>
Phase3Dashboard rendered an indefinite `<div class="animate-pulse">` skeleton when ml-prediction-service returned 503 (Phase 7.1 finding). Root cause: 4 `useQuery` hooks with `retry: 2` + exponential backoff kept `isLoading=true` for ~7s on every failed attempt; Playwright's `networkidle` fired during the inter-retry quiet period, so the smoke saw the skeleton mid-cycle.

Fix: short-circuit retry on 503 (feature-flag-off is permanent, retry is pointless). React Query settles to `isError=true` within one round-trip, TileState's branch-1 ErrorState renders, smoke sees `tile-error` testid inside `phase3-dashboard` testid with non-empty text content.

Then re-add Phase3Dashboard to the audit roster so the smoke validates the fix on every run.

This is a follow-up to Phase 7.1 — depends on nothing other than the running stack at /mnt/d/Bimo_max/crypto-trading-bot. Single 3-task plan.
</objective>
