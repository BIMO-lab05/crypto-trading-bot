<objective>
Add the per-test tape-cursor reset endpoint that the Phase 2 integration suite calls before every test (D-04). Plan 02-03's `tape_reset` function-scoped fixture HTTPs this route between tests so the recorded-tape data clock rewinds without rebooting bybit-connector. Endpoint is gated to tape mode only — refusing in live mode is a hard security boundary (HIGH severity threat).

Purpose: Per-test isolation of recorded-tape replay state. Without reset, a test that consumes 5 candles leaves the cursor at offset 5 for the next test — non-deterministic. With reset, every test starts at fixture position 0.

Output: A new `POST /admin/tape/reset` route on bybit-connector (port 8001), a `reset()` method on `TapeReplayClient` that zeroes per-symbol cursors, and unit tests asserting both layers.
</objective>

   ```python
   @app.post("/admin/tape/reset", tags=["Admin"])
   @limiter.limit("60/minute")
   async def reset_tape_cursor(
       request: Request,
       settings: Settings = Depends(get_settings),
   ):
       """Reset the tape replay cursor to fixture position 0 (D-04).

       Gated to MARKET_DATA_SOURCE=tape mode only. Refuses in live mode —
       state-mutating admin endpoint must not be reachable in production.
       Called by integration suite's `tape_reset` fixture before each test.
       """
       # D-04 + threat model HIGH: refuse outside tape mode.
       if settings.market_data_source != "tape":
           raise HTTPException(
               status_code=403,
               detail="tape/reset only available when MARKET_DATA_SOURCE=tape",
           )
       client = request.app.state.rest_client
       if not isinstance(client, TapeReplayClient):
           raise HTTPException(
               status_code=503,
               detail="tape client not initialized",
           )
       logger.warning("TAPE_REPLAY: cursor reset")
       client.reset()
       return {"success": True, "message": "tape cursor reset"}
   ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docker network → bybit-connector :8001 | Test fixture / container-internal callers reach the new admin route |
| operator env (.env) → settings.market_data_source | Mode flag controls whether the route accepts traffic |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | E (elevation) | POST /admin/tape/reset | mitigate | Refuse with HTTP 403 when `settings.market_data_source != "tape"`. Endpoint code gates BEFORE client lookup; verified by Task 2 Test 2 (live-mode → 403). |
| T-02-01-02 | T (tampering) | TapeReplayClient state | mitigate | reset() touches only in-memory cursors; never modifies fixture files (which are RO bind-mounted per docker-compose.unified.yml volume `tests/fixtures/tape:...:ro`). |
| T-02-01-03 | D (DoS) | rate-limit | mitigate | `@limiter.limit("60/minute")` matches per-test cadence (1 reset per test, ~10 tests × 6 retries < 60). Higher than circuit-breaker's `10/minute` because it's hit per-test. |
| T-02-01-04 | I (info disclosure) | log injection | mitigate | Log line is parameter-free static string `TAPE_REPLAY: cursor reset` — no operator-supplied input is logged. |
| T-02-01-05 | R (repudiation) | unaudited reset | accept | Reset is non-destructive (in-memory cursor zeroing); audit log via slowapi/uvicorn access logs is sufficient. No PII / financial impact. |
| T-02-01-06 | S (spoofing) | no-auth network exposure | accept | bybit-connector has no auth middleware (existing project pattern; protected upstream at api-gateway). Route is reachable only inside docker network when MARKET_DATA_SOURCE=tape. Production deploys MUST NOT set MARKET_DATA_SOURCE=tape (operator runbook responsibility — tracked in 02-07 RUNBOOK.md). |
</threat_model>
