2. Each of the 6 sections must contain `Diagnose / Action / Verification` blocks with concrete shell commands. Sources for content:

   **Symptom: BuildKit hang** (CLAUDE.md § Environment, line referencing "BuildKit hangs on WSL2"):
   - Diagnose: `docker context show` (must NOT be `desktop-linux`); `cat /proc/version | grep -i microsoft` (confirms WSL2); `docker compose -f docker-compose.unified.yml build` hangs >2min on a single service.
   - Action: `DOCKER_BUILDKIT=0 docker compose -f docker-compose.unified.yml build <svc>` OR `make build-no-buildkit SVC=<svc>` (target from Plan 02-10).
   - Verification: `docker compose -f docker-compose.unified.yml ps` shows service `Up (healthy)`; build log shows no stage stalls.

   **Symptom: Docker context misconfig** (CLAUDE.md § Environment):
   - Diagnose: `docker context show` returns `desktop-linux` (expected: `default`); errors like `error during connect: ... docker_engine: Get`.
   - Action: `docker context use default` then `docker context show` to confirm.
   - Verification: `docker info` returns server version + storage driver (no error).

   **Symptom: Bind-mount race** (CLAUDE.md § Environment):
   - Diagnose: Service errors with `PermissionError: /app/logs` OR `FileNotFoundError: tests/fixtures/tape` despite `docker inspect` showing the bind. `docker exec <svc> ls /app/logs` returns root-owned empty dir.
   - Action: `docker compose -f docker-compose.unified.yml up -d --force-recreate <svc>`.
   - Verification: `docker exec <svc> ls -la /app/logs` shows the host-mounted contents (not empty + non-root).

   **Symptom: Stale in-memory ML model** (CLAUDE.md § Gotchas — "GRU models 4+ months stale"; INFRA-06 named bug):
   - Diagnose: ML retrain script ran but `curl http://localhost:8007/api/v1/predictions/SOLUSDT` still returns predictions matching pre-retrain values; `docker logs ml-prediction-service | grep "model loaded"` shows old model_path.
   - Action: `docker compose -f docker-compose.unified.yml restart ml-prediction-service` (forces module reload). Per CLAUDE.md "Verification standards" — restart-on-config-change rule.
   - Verification: `docker logs ml-prediction-service --tail 20 | grep "model loaded"` shows the new model file path; `curl /api/v1/predictions/SOLUSDT` returns predictions differing from pre-restart values.
   - Cross-link: For long-term fix (mtime-watching reload hook), see Phase 2 Plan 02-08 (INFRA-06 triage).

   **Symptom: bootstrap.sh fails with one or more UNHEALTHY services**:
   - Diagnose: bootstrap.sh exit 1 with `[5/6] UNHEALTHY <svc>:<port>` lines printed; tail of `docker compose logs <svc>`.
   - Action: per service —
     - `sentiment-analysis`: `DOCKER_BUILDKIT=0 docker compose -f docker-compose.unified.yml build sentiment-analysis` (CLAUDE.md § Gotchas — PyPI timeout).
     - DB services (`postgres`/`timescaledb`): check container started; `docker exec <svc> pg_isready -U postgres`.
     - Bind-mount race: see "Bind-mount race" symptom above.
   - Verification: re-run `bash bootstrap.sh`; expect `[6/6] Bootstrap complete`. If still failing, run `bash scripts/iter-fix.sh` (Plan 02-06) for checkpointed iteration on the integration suite.

   **Symptom: EMERGENCY_STOP recovery**:
   - Diagnose: `ls EMERGENCY_STOP` shows file present; trading-engine logs show STEP-0 hold; or `curl /api/portfolio/emergency-stop/status` returns active.
   - Action (to disarm): `rm EMERGENCY_STOP` (or operator touches the API to clear the auto-flag) AND verify trading-engine has the file mount RO at `/app/EMERGENCY_STOP` (per CLAUDE.md "Project rules"). Restart trading-engine if file change not picked up: `docker compose -f docker-compose.unified.yml restart trading-engine`.
   - Verification: `ls EMERGENCY_STOP` shows file absent; `curl http://localhost:8005/api/v1/status` shows auto-trader engaged (or `docker logs trading-engine | grep -i "auto.trader.armed"`).

3. Cross-link to Makefile (Plan 02-10) and iter-fix.sh (Plan 02-06) where mentioned. The runbook is permitted to forward-reference these artifacts; Plan 02-08 may extend with one new section per deferred bug.
