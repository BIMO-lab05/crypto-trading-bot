<objective>
Build the Phase 6 tile audit deliverables (DASH-01): an operator-readable
markdown table, a machine-readable JSON sidecar, and a runtime probe script
that asserts every documented endpoint returns the recorded shape. Verdicts
in {FIXED, LABELED_STALE, REMOVED} drive Plan 6-05's tile refactor scope and
make Phase 6 finite (LABELED_STALE rolls to Phase 7 backlog; REMOVED is deleted).

The JSON sidecar additionally records each tile's `last_updated_at_emitter`
status (yes|no|n/a). Per the W-02 scope-down, Phase 6 only ships the
last_updated_at field on `/api/config/safety-state` (Plan 6-02) + relies on
`forceStale={true}` for LABELED_STALE tiles (Plan 6-05). Adding the field to
every tile-backing endpoint is Phase 7 work; this audit produces the inventory
Phase 7 needs.

Purpose: Eliminate broken/stale tiles by either fixing them, labelling them
"stale" in the UI, or removing them. The script is the regression gate the
recorded-tape stack runs in future CI.

Output: 06-TILE-AUDIT.md + 06-TILE-AUDIT.json + scripts/audit_tiles.py + scripts/test_audit_tiles.py.
</objective>
