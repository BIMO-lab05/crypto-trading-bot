## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner ↔ tournament-harness image | The runner pulls + builds the image fresh each job; no persistent layer trust across jobs |
| host tests directory ↔ container `/app/tests` mount | Read-only bind mount (`:ro`) — container cannot mutate the host test files even if compromised |
| pytest stdout ↔ CI pass/fail gate | The SKIPPED-grep guard is the only mechanism distinguishing "tests genuinely passed" from "tests silently skipped" |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-09-01 | Repudiation | container-integration job reports success while all tests SKIP | mitigate | `grep -E '^[0-9]+ skipped' /tmp/container-integration.log` + `exit 1` makes any SKIPPED test fail the job. Pairs with Plan 04-08's `test_canonical_metrics_importable.py` regression test — defence in depth |

CI failure on the unmarked test will force the contributor to read the comment |
| T-04-09-03 | Denial of service | `--no-cache` image build on every PR | accept | Solo operator; PR frequency is low; rebuild cost (~2-5 min) is acceptable for the correctness guarantee. Future optimization: layer caching via `docker/build-push-action@v5` — out of scope for gap closure |
