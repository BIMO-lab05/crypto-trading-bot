<objective>
Fix the `sharpe_lift = nan` bug surfaced by Plan 04-08's unskipping of the in-container e2e suite. When the baseline is the D-04 persistence series (`np.zeros_like(actual_log_ret)`), `probabilistic_sharpe_ratio(zeros, benchmark_sr=0.0)` returns `nan` (zero variance → division by zero in the PSR formula, documented in sharpe_metrics.py line 171-172). Subtracting nan from ens_sharpe propagates the nan into `sharpe_lift`, which then fails the `sharpe_lift > 0` check in `win_gate.evaluate_win_gate`, blocking every symbol from winning regardless of true edge.

Purpose: Restore the round-trip-winner path so the auto-PR pipeline is verifiably green end-to-end on the synthetic `drift=0.005` fixture. Without this, ROADMAP SC-1 (ensemble + bootstrap p-value vs persistence) and SC-3 (draft PR opened with correct argv shape) cannot be demonstrated.

Output: One inline guard + helper in `open_pr.py`; one new unit test file pinning the contract. Bootstrap kernel and canonical PSR/DSR chain remain untouched.
</objective>

       def _zero_safe_baseline_sharpe(baseline_log_ret: np.ndarray, *, var_eps: float = 1e-12) -> float:
           """Sharpe of the D-04 persistence baseline.

           PSR is undefined for a zero-variance series (returns nan per
           sharpe_metrics.probabilistic_sharpe_ratio docstring line 171-172).
           The persistence baseline is exactly that: predict last_close every
           step → log-return = 0 every bar → constant zero series. A constant
           baseline has no risk-adjusted return signal, so we define its Sharpe
           to be 0.0. Lift then reduces to the candidate's own PSR.

           IMPORTANT: This shortcut applies ONLY to the baseline. The candidate
           still flows through the full canonical PSR path. A genuinely flat
           candidate (`np.zeros`) yields candidate_psr = nan, lift = nan - 0 =
           nan, and win_gate records `sharpe_lift_non_positive` — the fix
           never masks a non-edge candidate.
           """
           arr = np.asarray(baseline_log_ret, dtype=float)
           if arr.size < 2:
               return 0.0
           if float(np.std(arr, ddof=1)) < var_eps:
