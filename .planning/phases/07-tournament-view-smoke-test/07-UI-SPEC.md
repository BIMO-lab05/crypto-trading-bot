## Typography

Three faces (already loaded by `index.html`); four roles on `/tournament`:

| Role | Family | Size | Weight | Line Height | Letter-spacing | Where used |
|------|--------|------|--------|-------------|----------------|------------|
| Display (page heading) | **Fraunces** | 28px | 500 (var `'opsz' 144`) | 1.2 | -0.025em | `<h1>Tournament Leaderboard</h1>` in page header |
| Eyebrow (column headers, tournament-selector label, filter-group labels) | **Manrope** | 10px | 600 | 1.2 | 0.18em uppercase | Every `<th>`, "TOURNAMENT", "SYMBOLS", "ARCHITECTURE", "STATUS" labels |
| Body (chip labels, button text, footer text, tooltip body, empty-state body) | **Manrope** | 13px | 500 | 1.5 | 0 | Filter chip labels (`SOL (12)`), "Clear filters" button, footer narrative, tooltip narrative |
| Numeric (every cell in the leaderboard table, p-values in tooltip, counts in chips, sort-indicator numerals) | **JetBrains Mono** | 13px | 500 | 1.4 | 0.01em | All `<td>` numeric cells; `(12)` count inside filter chips; p-values; `exported_at` / `git_sha` in footer |

**Rationale:** 4 sizes (28 / 13 / 13 / 10) → within the "must declare 3-4" gate. Two weights (500 + 600) → within the "max 2 weights" gate. Heading line-height 1.2, body 1.5 → matches recommended defaults. The 10px eyebrow + 0.18em letter-spacing combo is the established Editorial Trading Floor convention from `StatusBar.jsx:35` and `KeyMetricsStrip.jsx:103-110`; carrying it forward avoids visual drift.

**Tabular numerals:** every JetBrains Mono cell sets `fontFeatureSettings: '"tnum" 1, "zero" 1'` so digits don't dance on refetch — same pattern as `KeyMetricsStrip.jsx:129`.

## Interaction Spec

| Interaction | Behavior |
|-------------|----------|
| Click table header | Toggle sort: same column → reverse direction; different column → switch to that column with `desc`. URL params update. No animation; instant re-sort. |
| Click filter chip | Toggle membership in URL multi-select. Visual: `surface2` background + 1px `borderStrong` border when selected; `surface` background + 1px `border` border when unselected.
