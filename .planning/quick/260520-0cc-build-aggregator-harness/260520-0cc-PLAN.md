# Build aggregator-driven walk-forward harness

## Goal

Produce honest edge evidence for the LIVE ensemble strategy (`strategy_mode=ensemble`). All prior walk-forward runs measured deprecated phase1_prod or planned-but-not-deployed sqzmom_v2. The live aggregator's 10-indicator weighted vote + regime modifier + gatekeeper + validator pipeline has never been backtested.

## Architecture

**Dual-namespace import problem:** Live aggregator's modules use `from app.X` imports. TA indicator classes use `from app.X` too, but a *different* `app` namespace. Both services name their package `app`. Cannot have both on `sys.path` at the same time.

**Solution:** Load TA indicators first under TA's `app` namespace, capture class references, then purge `sys.modules["app.*"]`, then load TE aggregator under a synthetic `app.models` namespace built from TE's `enums.py` and `signal.py` directly. Bypasses TE's `models/__init__.py` (which pulls in stat_arb deps not needed here).

## Tasks

### T1: write backtesting/run_walk_forward_ensemble.py

**Files:**
- create: `backtesting/run_walk_forward_ensemble.py`

**Action:**
1. Set `SYMBOLS = ["SOLUSDT","BNBUSDT","ADAUSDT","BTCUSDT","ETHUSDT"]`, `DAYS=180`, `INTERVAL="60"`, `FOLDS=4`, `IS_FRAC=0.75`, `N_TRIALS=8` (honest count: phase1_prod, sqzmom_v2 L0..L5, ensemble = 8).
2. **TA load phase:** prepend `services/technical-analysis` to `sys.path`. Import RSICalculator, MACDCalculator, BollingerBandsCalculator, SMACalculator, EMACalculator, Stochastic, IchimokuCloud, ADXCalculator, ATR, TrendFilter, VolumeConfirmation. Capture references.
3. **Purge:** `for k in list(sys.modules): if k=="app" or k.startswith("app."): del sys.modules[k]`. Remove TA path from `sys.path`.
4. **TE load phase:** prepend `services/trading-engine` to `sys.path`. Use `importlib.util.spec_from_file_location` to load `app.models.enums` and `app.models.signal` directly. Build a stub `app.models` module exposing `SignalAction`, `IndicatorSignal`, `TradingSignal`. Register in `sys.modules`. Stub `app.config.get_settings` with a minimal namespace (since aggregator_core imports `get_settings`). Then `from app.aggregation.aggregator_core import CoreAggregator` and `from app.aggregation.market_regime import RegimeAnalysis, MarketRegime, TrendDirection`.
5. **precompute_features(df):** one causal pass over OHLCV, emits columns: rsi9, macd, macd_signal_line, bb_*, sma21, ema21, stoch_k/d, ichi_*, adx, plus_di, minus_di, adx_regime_str, adx_direction_str, adx_conf, atr14, atr_pct, vol_ratio, trend_str. Uses TA calculators' `calculate_with_signal` where available, else `calculate`. Each step uses `data[:idx+1]` (no peek).
6. **build_indicators_dict(row):** for each indicator column triple `(value, signal_str, conf)`, construct `IndicatorSignal(name=X, signal=SignalAction(signal_str), confidence=conf, value=value, metadata={"weight": W})`. Weights match live: ICHIMOKU=0.9, others=1.0. Include TREND_FILTER (gatekeeper), VOLUME_CONFIRMATION (validator). Return dict.
7. **build_regime(row):** construct RegimeAnalysis from precomputed adx_*, adx_regime_str, adx_direction_str using MarketRegime/TrendDirection enums. Apply confidence_modifier table from market_regime.py: STRONG_TREND→1.2, TRENDING→1.1, WEAK_TREND→1.0, RANGING→0.8, VOLATILE→0.7, UNKNOWN→1.0.
8. **build_atr_data(row):** dict with stop_loss_long/short, take_profit_long/short derived from ATR (multiplier defaults: 1.5×ATR stop, 3.0×ATR TP — matches sqzmom_v2 / ADR-013 R/R 2:1).
9. **ensemble_strategy(row, position, idx, data) callable** — required signature for BacktestEngine:
   - `if idx < 200: return None` (warmup for 200-EMA-aware indicators).
   - Build indicators dict, regime, atr_data from precomputed row.
   - `signal = aggregator.aggregate_signals(indicators, timestamp_ms, atr_data, regime_analysis)`.
   - If `signal.action == SignalAction.BUY`: return `{"action":"BUY","stop_loss":atr_data["stop_loss_long"],"take_profit":atr_data["take_profit_long"], "metadata":{"confidence":signal.confidence, "score":signal.aggregated_score, "consensus":signal.consensus_count}}`.
   - SELL: mirror.
   - HOLD/NEUTRAL: return None.
10. **Walk-forward driver** (mirror `run_walk_forward_sqzmom_v2.py`):
    - download 180d 60m via HistoricalDataDownloader from `http://localhost:8002`
    - filter `is_mainnet=True` if column present (ADR-013 testnet-taint guard)
    - precompute_features once
    - 4 folds anchored, IS-frac 0.75; in each fold run IS + OOS through BacktestEngine
    - per-fold: trades, WR, Sharpe, MaxDD, PF, PnL%
    - OOS mean Sharpe across folds, OOS/IS ratio, DSR via Bailey & Lopez de Prado
    - Gate: OOS Sharpe ≥ 1.0, OOS/IS ≥ 0.6, DSR ≥ 0.95, max DD < 30%, PF mean ≥ 1.2 (ADR-013 thresholds).
11. **Output:** print per-symbol summary, write `backtesting/results/wf_ensemble_2026-05-20/{SYMBOL}_summary.txt` + `_progress.log` mirroring existing layout.

**Verify:**
- `python3 -c "import ast; ast.parse(open('backtesting/run_walk_forward_ensemble.py').read())"` succeeds (syntax check).
- Import-only dry run: file imports clean without running main (`python3 -c "import backtesting.run_walk_forward_ensemble"` — may need PYTHONPATH or skip if `if __name__` guards prevent network).

**Done:** file exists, syntactically valid, dual-import scaffolding in place.

## Risks

- **TE config.get_settings()** may pull in env-validated fields (e.g. requires `RABBITMQ_URL`). Mitigation: stub `app.config` in sys.modules with a fake `get_settings` returning a SimpleNamespace with only the fields aggregator uses (`technical_analysis_url`, etc.).
- **MarketRegimeDetector**'s `__init__` may try httpx connection. Mitigation: pass `enabled=False` OR construct RegimeAnalysis directly without invoking the detector class. Aggregator only needs the `regime_analysis` param.
- **ATR multipliers** — live uses dynamic ATR from TA endpoint with service-side config. Backtest uses inline multipliers (1.5/3.0). Document discrepancy.
- **Live `SignalCache`** — aggregator initializes with `enabled=False` already; no caching impact.
- **Voter `aggregation_threshold=0.15`** — passed in aggregator_core constructor; default holds.
- **Output may show 0 trades.** That is itself the finding. Don't tune to pass.
