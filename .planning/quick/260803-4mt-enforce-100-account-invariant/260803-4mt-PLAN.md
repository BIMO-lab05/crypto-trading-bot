**Detection rules.** A violation is a numeric literal (int/float/`Decimal("...")`) supplied
as the value for a *capital-named* target, in any of these AST shapes:

1. `ast.Assign` / `ast.AnnAssign` where the target id matches the capital-name pattern.

3. `Field(default=<num>)`, `Field(default=Decimal("<num>"))`, `Query(default=<num>)`,

account_equity|portfolio_value|total_capital|total_value|final_capital|peak_capital|
