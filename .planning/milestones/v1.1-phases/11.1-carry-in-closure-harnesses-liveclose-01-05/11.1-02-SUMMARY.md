## Decisions Made

- **AWAITING_HUMAN on technical success (not COMPLETE).** Plan-1 schema enum accepts both; ROADMAP success criterion for LIVECLOSE-01 keeps `human_needed=true` because the operator still has to commit the evidence file and flip `.planning/state/carry_ins.json`. The harness writes the file; the operator commits and flips.
- **DRY_RUN heredoc prints the fixture verbatim.** Avoids regex line-matching in the test. When the contract drifts (line added / re-worded), the fixture and the heredoc must both be edited — a small TOFU cost in exchange for trivial failure diagnostics.
- **15-service compose ps threshold.** CLAUDE.md states the canonical stack is 15 services via `docker-compose.unified.yml`. Harness counts rows with `State.lower() == 'running'` from the compose-ps JSON output and downgrades to FAILED if either run reports `<15`. Matches the operator-facing health-probe expectation in `bootstrap.sh:67-117`.
- **Repo-root resolution requires `git rev-parse --show-toplevel` to succeed.** The evidence file must land in the operator's actual repo so it can be committed; running the harness from outside a git checkout would write the evidence into the wrong tree. Refuse rather than guess.
