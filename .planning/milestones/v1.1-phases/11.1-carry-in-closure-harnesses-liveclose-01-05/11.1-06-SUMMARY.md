## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] --revert-only fast path silently failed to revert (caught during advisor self-review)**
- **Found during:** post-GREEN advisor self-review (before SUMMARY commit).
- **Issue:** The `--revert-only` branch set `FLIP_ATTEMPTED=1` and `exit 0` BEFORE the `trap revert_to_paper EXIT INT TERM` line further down in the supervised-flip path. The trap was never registered, so the revert function never ran. An operator hitting `--revert-only` to recover from an interrupted prior flip would see "Running revert-only path" + `exit 0` + zero docker calls. Stack would stay on `TRADING_MODE=LIVE` if that's where the interrupted previous run left it.
- **Fix:** Call `revert_to_paper` directly in the `--revert-only` branch instead of relying on the trap. The script header comment, `--help` text, and runbook all advertise this recovery path; the fix matches their contract.
- **Files modified:** `scripts/closure/liveclose-05-live-flip-smoke.sh`.
- **Commit:** `b8d0ca0`.

**2. [Rule 1 - Bug] write-evidence call referenced PAPER_AFTER_RESPONSE_PATH before the file existed (caught during advisor self-review)**
- **Found during:** post-GREEN advisor self-review (same review pass as #1).
- **Issue:** Main flow called `python3 -m scripts.closure._common write-evidence` BEFORE the EXIT trap fired the post-revert probe. The resulting evidence JSON's `evidence_paths` array listed `PAPER_AFTER_RESPONSE_PATH` as a dangling reference for ~10s while the trap ran. A reviewer reading the JSON within that ~10s window would find the path doesn't exist yet.
- **Fix:** Restructured main flow to explicitly call `revert_to_paper` AFTER the operator-ENTER prompt and BEFORE the write-evidence call. Introduced `REVERT_DONE` idempotency flag so the EXIT trap re-firing on normal script exit is a no-op (returns the saved exit code unchanged). The trap stays registered as fallback for error paths (set -e tripping, SIGINT/SIGTERM mid-flight).
- **Files modified:** `scripts/closure/liveclose-05-live-flip-smoke.sh`.
- **Commit:** `b8d0ca0` (bundled with the --revert-only fix since both touched the same control-flow region).
