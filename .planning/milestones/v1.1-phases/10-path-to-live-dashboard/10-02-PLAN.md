<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> api-gateway (carry-ins + live-readiness endpoints) | Unauthenticated read-only fetch from the dashboard. |
| api-gateway JSON response -> React render (carry-in descriptions, check.detail strings) | Server-controlled strings; React's default JSX text escaping is the only sanitisation. |
| client-side overall computation | Explicitly NOT a trust boundary in this design — server is authoritative per D-10-04 + D-10-16; client renders only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-02-01 | Tampering | Compromised api-gateway returns fabricated `overall="READY"` to unlock LIVE-flip messaging | accept | The tile is a visibility surface, not an enforcement surface. PREFLIGHT-02 (Phase 8) refuses to boot trading-engine in LIVE with cap > 2%, regardless of what the dashboard renders. The four-flag LIVE gate (CLAUDE.md) is the actual control plane; the tile is informational. |
| T-10-02-02 | Information disclosure | XSS via crafted carry-in `description` or `check.detail` rendered into the DOM | mitigate | All text content goes through standard JSX `{variable}` interpolation, which React escapes by default. The component does not use any raw-HTML injection prop. No `eval`, no direct DOM `innerHTML` writes. Description strings are operator-authored in `.planning/state/carry_ins.json` and reviewed via git diff. |
| T-10-02-03 | Denial of service | Tile crash on null/malformed payload could blank the dashboard | mitigate | Tile is wrapped in TileState; on `query.isError` TileState renders Failed/Retry UI and children never render (CONTEXT.md D-14 from Phase 6). Defensive null-checks on `carryInsQuery.data.live_readiness?.checks`, `carryInsQuery.data.carry_ins`, and `carryInsQuery.data.window` prevent runtime errors. Optional-chaining used throughout. |
| T-10-02-04 | Spoofing | Client recomputes `overall` and disagrees with server, misleading operator | mitigate | Component reads `carryInsQuery.data.overall` directly per D-10-04 — no client-side recomputation.
