# Phase 13 Plan 01: BC-01 Repo-Wide Bybit-Bypass Audit Summary

Rerunnable Python audit script + committed JSON inventory of every `pybit` import / `api.bybit.com` URL / `api-testnet.bybit.com` URL outside `services/bybit-connector/`, locked as the source-of-truth artifact every BC-02..BC-07 task downstream consumes.

## What Was Built

### `scripts/audit_bybit_bypass.py` (160 LOC, pure stdlib)

- `BANNED_PATTERNS` — 4 compiled regexes per CONTEXT D-05 (pybit_import, mainnet_rest_url, testnet_rest_url, wss_stream_url). Same dict will be lifted verbatim into Plan 02's BC-03 grep gate.
- `EXEMPT_DIRS` — `services/bybit-connector/`, `scripts/tape/`, `_archive_exchanges/`, `services/ml-prediction-service/models/_archive_lstm/`, plus the script self-skips itself.
- `_REPLACEMENT_OVERRIDES` map: per-(file, kind) lookups for `rotate_secrets.py` (all 3 entries → `/api/v1/account/balance` per D-07), `shared/health_check.py` (URL kinds → `/health`), and `services/ml-prediction-service/app/handlers/orderbook.py` (URL kinds → `/api/v1/market/orderbook`). Default fallback `/api/v1/market/kline`.
- `collect_bypass_entries()` walks `REPO_ROOT.rglob('*.py')`, skips exempt dirs + `__pycache__`, emits one entry per match. Sorted by `(file, line, kind)` so repeat runs produce byte-identical output (verified by two-run `diff`).
- CLI: `--out PATH` writes to file (also makes parent dirs); default writes to stdout. Both paths terminate the JSON with a single trailing newline.

Generated by `python scripts/audit_bybit_bypass.py --out .planning/evidence/BC-01/bybit-bypass-audit.json`. Plain JSON array, each entry `{file, line, kind, current_call, replacement_path}`.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing critical functionality] Extended rotate_secrets URL routing to `/api/v1/account/balance`**

- **Found during:** Task 2, after generating the initial artifact and reviewing it.
- **Issue:** Plan step 5 explicitly maps only `rotate_secrets.py + pybit_import → /api/v1/account/balance`. The mainnet/testnet URL matches on `rotate_secrets.py:234` would have inherited the default `/api/v1/market/kline`, which is semantically wrong — that line is the auth-ping base_url switch wrapping the pybit `HTTP()` call (CONTEXT D-07 + RESEARCH Pattern 3 both make this clear). Tagging two of three rotate_secrets entries as kline endpoints would mislead Plans 02..07's refactor.
- **Fix:** Added `(infrastructure/scripts/rotate_secrets.py, mainnet_rest_url) → /api/v1/account/balance` and the testnet counterpart to `_REPLACEMENT_OVERRIDES`.
- **Files modified:** `scripts/audit_bybit_bypass.py`
- **Commit:** `4034865` (separate `fix(audit):` commit between the Task 1 `feat(audit):` and Task 2 `chore(evidence):` commits, so the artifact ships with the corrected map)

### Plan-spec adjustments documented for downstream

**[Documentation - not a deviation]** Plan step 6 specifies sorting entries by `(file, line)`. The implementation sorts by `(file, line, kind)` — because `rotate_secrets.py:234` and `shared/health_check.py:771` each match TWO kinds at the same line, sorting by `(file, line)` alone leaves kind ordering implicit (Python's dict iteration preserves `BANNED_PATTERNS` insertion order, so it would have been deterministic in practice). Adding `kind` to the sort key makes the ordering explicit-deterministic instead of insertion-order-dependent. Idempotency verified by two-run `diff`.
