BC-01 JSON schema (locked by CONTEXT BC-01):
- Top-level: JSON array of entries
- Each entry: {"file": str, "line": int, "kind": str, "current_call": str, "replacement_path": str}
- kind values: "pybit_import" | "mainnet_rest_url" | "testnet_rest_url" | "wss_stream_url"
- file: repo-relative POSIX path
- line: 1-based line number where match occurred
- current_call: the exact source line stripped
- replacement_path: the bybit-connector REST path the refactor will target (e.g. "/api/v1/market/orderbook"; for pybit_import in rotate_secrets use "/api/v1/account/balance"; for shared/health_check use "/health")

- pybit_import: ^\s*(from\s+pybit\b|import\s+pybit\b)  (MULTILINE)
- mainnet_rest_url: https?://api\.bybit\.com
- testnet_rest_url: https?://api-testnet\.bybit\.com
- wss_stream_url: wss?://stream(?:-testnet)?\.bybit

- services/bybit-connector/
- scripts/tape/
- _archive_exchanges/                                 (post-BC-04 archive)
