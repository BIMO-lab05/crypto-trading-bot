```
## Symptom: Market-data stale or missing — bybit-connector chain broken

[1-2 sentence problem description]

**Diagnose:**

Sub-cause A — bybit-connector container down
- `docker ps | grep bybit-connector` — no entry / Exited status
- `docker logs crypto-bot-bybit-connector --tail 30` — last lines show crash or shutdown

Sub-cause B — BYBIT_CONNECTOR_URL env misconfigured
- (host vs compose hostname per RESEARCH Pitfall 1)
- `docker exec crypto-bot-market-data env | grep BYBIT_CONNECTOR_URL` — wrong value
- (operator on host running script with compose-style URL `bybit-connector:8001` triggers DNS failure)

Sub-cause C — bybit-connector hitting Bybit-side ratelimit
- `docker logs crypto-bot-bybit-connector --tail 50 | grep -i "ratelimit\|rate.limit\|429"`
- bybit-connector exposes ratelimit headers in its own logs

Sub-cause D — MARKET_DATA_SOURCE=tape accidentally enabled in production
- `docker exec crypto-bot-bybit-connector env | grep MARKET_DATA_SOURCE` — value is `tape`
- (production should always be `live`)

**Action:**

For sub-cause A:
```
docker compose -f docker-compose.unified.yml up -d bybit-connector
```

For sub-cause B (host case):
```
export BYBIT_CONNECTOR_URL=http://localhost:8001
```

For sub-cause C: wait or contact Bybit support; ratelimit eventually clears.

For sub-cause D:
```
docker exec crypto-bot-bybit-connector sh -c 'unset MARKET_DATA_SOURCE'
# OR fix docker-compose.unified.yml MARKET_DATA_SOURCE override and re-up
docker compose -f docker-compose.unified.yml up -d --force-recreate bybit-connector
```

**Verification:**

```
curl http://bybit-connector:8001/api/v1/market/ticker?symbol=BTCUSDT
```

Expected: `{"success": true, "data": {"category": "linear", "list": [{"symbol": "BTCUSDT", "lastPrice": "...", ...}]}}` within 2s. If `success: false` or non-2xx, the chain is still broken — recurse to Diagnose sub-causes.
```
