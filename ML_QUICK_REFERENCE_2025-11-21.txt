8. TROUBLESHOOTING
================================================================================

Container exited?
  → Normal. Training is complete, models are saved to disk.
  → Container can be restarted with: docker restart crypto-bot-ml-prediction

Database connection failed?
  → Check TimescaleDB is running: docker ps | grep timescaledb
  → Verify port 5433 is open: netstat -tulpn | grep 5433

Optimization too slow?
  → Normal. CPU-based training is slower. Can reduce trials from 50 to 30.
  → Check CPU usage: top -p $(pgrep -f hyperparameter_optimizer)

Out of memory?
  → Reduce batch size from 64 to 32 in hyperparameter_optimizer.py
  → Or reduce trials from 50 to 30

Models not improving?
  → Try with all 89 days data instead of 30
  → Increase trials from 50 to 100
  → Enable GPU if available (uncomment in code)
