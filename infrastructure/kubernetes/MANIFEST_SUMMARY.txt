TROUBLESHOOTING
================================================================================

Common Issues:

1. Pods in CrashLoopBackOff
   → Check logs: kubectl logs <pod> -n crypto-bot --previous
   → Check events: kubectl describe pod <pod> -n crypto-bot

2. PVC Not Binding
   → Check storage class: kubectl get sc
   → Verify dynamic provisioning

3. Database Connection Errors
   → Verify secrets: kubectl get secret db-secrets -n crypto-bot -o yaml
   → Test connectivity from debug pod

4. Service Not Accessible
   → Check endpoints: kubectl get endpoints -n crypto-bot
   → Verify service selector matches pod labels

5. High Resource Usage
   → Check metrics: kubectl top pods -n crypto-bot
   → Review resource limits
   → Consider scaling up

Debug Tools:
  - Interactive debug pod with netshoot
  - Port forwarding for local access
  - Log streaming
  - Event monitoring
