================================================================================
OUTLIER DETECTION METHODS
================================================================================

1. Z-SCORE METHOD
   ┌────────────────────────────────────────────┐
   │ z = (x - μ) / σ                            │
   │                                             │
   │ Outlier if |z| > 3.0                       │
   │                                             │
   │ Example: BTCUSDT                           │
   │   Mean:  $67,500                           │
   │   StdDev: $1,200                           │
   │   Price:  $71,200                          │
   │   Z-score: 3.08 → OUTLIER                  │
   └────────────────────────────────────────────┘

2. IQR METHOD
   ┌────────────────────────────────────────────┐
   │ IQR = Q3 - Q1                              │
   │ Lower = Q1 - 1.5 × IQR                     │
   │ Upper = Q3 + 1.5 × IQR                     │
   │                                             │
   │ Example: BNBUSDT                           │
   │   Q1:    $589                              │
   │   Q3:    $625                              │
   │   IQR:   $36                               │
   │   Upper: $679                              │
   │   Price: $745 → OUTLIER                    │
   └────────────────────────────────────────────┘

3. PRICE JUMP DETECTION
   ┌────────────────────────────────────────────┐
   │ pct_change = |close[t] - close[t-1]|       │
   │              ─────────────────────          │
   │                  close[t-1]                 │
   │                                             │
   │ Outlier if pct_change > 0.20 (20%)         │
   │                                             │
   │ Example: SOLUSDT                           │
   │   Previous: $125.50                        │
   │   Current:  $152.30                        │
   │   Change:   21.3% → OUTLIER                │
   └────────────────────────────────────────────┘

4. OHLCV CONSISTENCY
   ┌────────────────────────────────────────────┐
   │ Valid conditions:                          │
   │   ✓ High >= Low                            │
   │   ✓ High >= Open, Close                    │
   │   ✓ Low <= Open, Close                     │
   │   ✓ All prices > 0                         │
   │   ✓ Volume >= 0                            │
   │                                             │
   │ Example: Invalid candle                    │
   │   Open:  $125.50                           │
   │   High:  $123.00  ← ERROR (High < Open)    │
   │   Low:   $122.00                           │
   │   Close: $124.50                           │
   └────────────────────────────────────────────┘
