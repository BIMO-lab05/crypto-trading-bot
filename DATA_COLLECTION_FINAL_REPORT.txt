KEY LEARNINGS
================================================================================

1. Bybit Connector Limitations
   - Service returns only latest candles (no time range support)
   - Testnet may have limited historical availability
   - Consider public API for extended history

2. Rate Limiting Strategy
   - Start with conservative delays (2-3s between requests)
   - Implement exponential backoff starting at 30s
   - Monitor HTTP 429 responses carefully

3. Data Deduplication
   - Use ON CONFLICT DO UPDATE for upserts
   - Still watch for edge cases with overlapping data
   - Deduplicate at end of collection cycle

4. AsyncPG Performance
   - Batch operations are fast (98+ records/second)
   - Connection pooling essential for throughput
   - Proper cleanup needed to avoid resource leaks
